# Claude Code Project Rules

Before every task:

1. Read AGENTS.md.
2. Treat AGENTS.md as authoritative.
3. Respect member ownership boundaries.
4. Do not modify files outside the current member's ownership unless explicitly requested.
5. Never change shared contracts without explicit team approval.
6. Inspect existing code before implementing.
7. Do not duplicate existing functionality.
8. Run tests after implementation.
9. Never commit secrets.
10. Never modify .github/workflows/validate.yml.
11. Keep changes minimal and focused.
12. The official Bobathon repository structure is authoritative. All application source code belongs under src/.

If a task conflicts with AGENTS.md:
STOP and ask for clarification.
